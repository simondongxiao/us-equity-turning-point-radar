# 概率模型规范

## 一、对象与时间
默认研究方向是做多机会与持有下行风险，风险高不自动等于可做空。若未来增加空头模型，须另设借券、成本和交易标签，不能把做多概率简单取反。

短期修复1—3个交易日；阶段周期5、10、21个交易日。页面默认10日，切换周期时价格区间、概率、机会和风险都必须同步切换。比较排名必须使用相同as_of、horizon、策略规则和可比模型校准口径。

交易日以交易所日历和America/New_York判定，展示同时给纽约时间与北京时间。财报/新闻存event_time、published_at、first_seen_at、source_updated_at、retrieved_at；旧文更新不能自动当新事件。使用截止时点已经获得的信息。调整复权、公司分拆、ADR比例、ticker更名、交易所变化和拆股。

## 二、五层证据
### 市场情绪与持续时间
采用软状态：趋势上行/整理、调整扩散、恐慌扩张、卖压缓和、修复启动、修复失败。它们可以跳转与反复，不必按固定序列走。
特征：连跌天数、连续下跌片段持续时间、ATR标准化累计跌幅、回撤、涨跌家数/新低比例、等权与市值加权差、收盘区间位置、量价、5/20日波动变化。分钟数据足够时才加入尾盘卖压、日内reclaim和广度变化；日线不能冒充尾盘信息。
同时估计“短期修复机会”和“继续极端下跌”——两者可同时上升。一天微涨不必强制清空调整持续时间。基本面重定价与暂时仓位冲击分开，事件类型是条件变量。

### 行业轮动
只读复用美股复盘统一的rotation_snapshot，记录as_of、created_at、source/model_version、market_state、sector_state、relative_strength、RS_change、duration、breadth、confidence、data_coverage。若接口不存在，在新项目建立适配器/共享产物，不修改旧Skill；缺失时以本项目明确标记的回退状态运行。
严格检查快照信息截止<=预测时点。历史回测不得使用事后生成或未来行情训练出的当日轮动状态。
比较市场风险分配、科技/非科技、硬件/软件、半导体子链、Mag7内部、等权与权重。Mag7与行业篮子重叠，不能重复计权。估计领先延续与领先切换两种可能，不强制均值回归；价格差只是相对表现证据，不冒充已测得净资金流。

### 个股独立表现
使用滚动或收缩beta，r_i=beta_m*r_m + beta_s*r_sector_residual + epsilon_i。行业篮子尽量剔除自身，尤其大权重股。看残差趋势、相对强度及变化、同行广度、结构/成交量、近期事件。市场/行业先验与个股修正不能要求三层总是同向。
必须允许：指数见底个股未见底；指数反弹前期防御赢家转弱；指数下跌个股先见底；板块切换导致技术突破失败。绝对收益概率与跑赢基准概率分别输出。

### 结构价带
保留前高前低、缺口、已确认swing的Fib、均线/AVWAP、ATR/Chandelier、reclaim及失败突破。锚点算法须有确认延迟，不使用事后ZigZag端点。水平线聚类为有宽度的区域，不迷信小数点。
同源价格特征用正则化、分组消融和样本外增量检验处理，不主观独立计票；Fib不是强制特征，无增量可降权或移除。
确认可研究收盘越过价带、ATR缓冲、保持时间、放量与相对强弱，但成交量大不能在价格根本没突破时单独触发“突破确认”。参数冻结后回测。触发后重新计算剩余赔率，而非机械激活目标。

### 波动、期权与事件
市场VIX/VXN的水平、分位、变化、期限结构作为风险状态输入，不是方向开关。个股用RV5/RV20与相匹配期限的IV、偏斜、期限结构、事件日。RV历史窗口与IV未来窗口不是同一对象，不能简单比值推出未来方向或期权错价。
期权隐含分布为风险中性信息，须映射/校准到真实世界概率。OI、成交量、put/call与dealer净Gamma不可互相替代；无法识别头寸时Gamma标为估计或缺失。不要求期权模块才能启动基础模型。新闻事件读取正文并保存证据，不只看标题。模型只取结构化时点特征；语言模型负责摘要，不生成概率和目标价数字。

## 三、标签
预先版本化每个标签、价位边界及持续要求。
1. 修复：1—3日内首次到达上涨目标，先于下跌边界；另存“曾经反弹”但不拿它作交易胜率。
2. 阶段底：未来H日低点距当前价格不超过delta*ATR_t，期间反弹至少a*ATR_t，期限末保持至少b*ATR_t。顶部独立或对应定义，检查底/顶事件是否可同时发生，不把不互斥标签强制归一。
3. 首次触达：同一固定U、D和H下，上边界先触达/下边界先触达/到期两者未触达；三类和为1。
4. 交易结果：指定入场、执行成本、止盈止损、跳空成交、到期退出得到R_net，不使用阶段底部概率代替交易成功概率。
δ、a、b及上下边界只在训练窗口中有限选型，冻结后评估。未来数据只做标签，不进入特征。标签成熟后才能训练和评价。

日线同一根bar触及U和D但顺序未知：记录ambiguous，不强行当真实上先/下先标签。主模型可使用删失/区间方法；简化模型剔除并报告选择比例及敏感性边界。交易回测采用保守顺序，同时报告上下界。不能把保守假设当已观测事实。

## 四、模型与共同路径分布
生产起点：正则化的离散时间竞争风险模型。日k、此前两边均未命中时，softmax给q_U(k)、q_D(k)、q_0(k)。
P_U(H)=sum_k survival(k-1)*q_U(k)
P_D(H)=sum_k survival(k-1)*q_D(k)
P_0(H)=survival(H)
不能把每天独立分类概率直接相加。未来尚未观测的状态变化需由路径模拟生成；不能把未来真实特征代入每一天的hazard。

市场/行业状态形成基准，个股特征及交互修正；若两阶段堆叠，第二阶段必须用第一阶段按时间产生的样本外预测。允许回退为正则化多项逻辑模型+时间标签，但模型卡明确实现等级，不冒充完整持续时间模型。

参考价格路径引擎：对点时可得历史片段按市场、行业、个股残差、波动及事件状态匹配，保留同期市场/行业/个股协动及片段顺序；用同一模型的风险与首次触达约束进行保守重加权，使用收缩与有效样本量检查。片段按事前已知波动归一后映射到当前，保持O/H/L/C几何关系与跳空。

只允许一个规范化的scenario-set作为对外概率与价带的共同来源。重加权造成极端权重、约束不可满足或有效样本不足时降级/不发布，不用几套互相冲突的概率拼成页面。抽样条数不是独立历史样本量。

从共同路径计算：
- 期限末收盘分布（P10/P50/P90及经验证的覆盖区间）；
- 期间最低价/最高价分布；
- 条件于阶段底/顶形成的转折价带，必须同时给该条件的发生概率；
- 固定价位期间触达概率、上先/下先/未触达；
- 绝对收益、超额收益、回撤、执行策略R_net。
固定价位随期限延长触达概率不得下降。期间极值的路径关系必须一致；期限末区间不必机械嵌套。边际P10-P90不等于整个未来路径有80%概率都在其中。

截图的“核心底顶”改为有明确定义的潜在价带；“普通/尾部极限”改为常态/尾部风险区间，不承诺不会越界。不能为贴合技术位手工移动分位数。日内跳空、财报和结构失效要有单独风险情景，不能靠最近平静历史给出近零尾部。

## 五、机会与风险排序（不能混成人气榜）
页面必须有四个按钮：机会↓（大到小）、机会↑（小到大）、风险↓（大到小）、风险↑（小到大）。默认机会↓，最近一次用户选择可存本地偏好，但不得存密钥。

默认同一10日做多参考策略比较；用户切换5/21日重算对应列与排序。参考策略版本固定；首版可以采用次日正常交易时段开盘入场、以t时已知ATR定义对称规则化边界、到期退出。具体执行价直到开盘才确定；当前详情展示参考价格与绝非已成交的计划。

风险不是1-机会。优先定义独立的资产路径风险：
D_j = max(0, 1 - min_{1..H}(P_j)/P_ref)
risk_value = ES95(D_j)，即最差5%情景中最大不利幅度的均值，正数越大风险越大。
辅助显示未来亏损概率、向下首次触达、事件/缺口风险及更长21日风险，不用紧止损把股票本身风险压成很低。

机会定义为可执行策略净期望及其估计不确定性：
mu_LCB = 对E[R_net]做时间/事件分块评估获得的保守置信下界
opportunity_value = mu_LCB / max(risk_value, epsilon)
epsilon由训练及稳定性规则预先确定；不能为了把某股排第一临时调分母。LCB是期望估计的不确定性，不是收益分布的5%分位数。未能可靠估计LCB时展示点估计且标低可信，不冒充保守下界。

机会0—100和风险0—100只是同一期同一合格池中的横截面分位，明确标“相对排名分”，不是百分比概率。排序以未舍入数值为准，tie-break用symbol稳定排序。机会分高也可能mu_LCB<=0，届时标“本轮无正优势”，不可强推第一名。高机会高风险可以同时存在。

未校准/不足样本/过期/数据异常股票仍在名单中，置底并显示不可比较；风险缺失不能当0，任何升降序下未知项都置底。临时股默认独立列表，与100股比较时用冻结常态池的经验分布映射，不改变整张榜单的评分基准。

## 六、凯利与执行
使用共同路径的实际R_net做稳健/分数凯利：max_f sum_j w_j log(1+f R_j)，考虑f范围、极端跳空损失、分布不确定性、相关仓位和回撤预算。不允许f让任一压力情景财富<=0。
没有用户股票账户资本/持仓时不猜账户金额、不从其他期货项目搬用3.7万元。页面只给单位风险或参考暴露上限及假设，不输出伪精确买入股数。分数凯利是风险约束参考，不是自动下单授权。
比较立即试探与等待确认的完整策略分布；确认后价格改变会损害赔率，不单纯因胜率上升就扩大仓位。没有正优势允许观望；保护边界不保证跳空按该价成交。

## 七、冷启动与降级
状态至少有：structural_only / uncalibrated / calibrated_low_confidence / calibrated / stale / data_error。只有经真实样本外检验与校准且口径匹配的结果，才能进入正式概率比较榜；其他状态仍展示可核验结构位、常规历史波动参考与缺口，但不伪造阶段顶底概率。
新股采用可审计的行业/相似股收缩先验，显示其不是该股自身长期历史验证。数据不足可以不预测，不能保证100只都有可靠概率。

## 八、v1.1存储轮动增量（不替换前七节）
执行`references/storage-memory.md`。存储主组独立，DRAM/HBM、NAND/SSD与HDD保留业务区别；先验使用按发行人LOO和时间有效的同行。少数同行仅为proxy，不假造行业广度；重叠篮子不独立计票。新增特征通过原竞争风险→共同路径→概率/价带→净收益管线，不能另外主观修改最终概率。

身份/业务分类变化使用taxonomy_version与membership_version并存；新旧模型需各自特征/校准版本与样本外对照。市场修复不强制存储或个股见底，MU上涨不自动确认SNDK/WDC/STX。完整规则和增量回测要求见存储规范。
