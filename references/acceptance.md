# 验收清单：逐条PASS / FAIL / BLOCKED

## 交付边界
- 新项目在D:\codex，旧Skill/旧行情仓库没有意外修改；检查修改清单。
- 有可调用SKILL.md与完整可执行项目，不只创建目录/空函数/TODO。
- 真实数据、合成测试、界面模板、历史验证、上线状态分别报告。

## 股票池
- 首版种子100个唯一发行人/有效代码；60/40研究覆盖桶不是伪GICS。
- 首次按近期真实数据检验资格与人气，至少300只母池或说明真实范围。
- 每周点时调池、稳定缓冲、无强制换满、科技优先且非科技>=30；历史成员保留。
- 临时个股不挤占100，失效代码/股份别名/公司行动正确处理。

## 数据与模型
- 5/10/21交易日周期与1—3日修复区分；所有时间使用同一信息截止。
- 数据读取正文、有原文时间、不反复把旧新闻当新催化。
- 市场、行业、个股可不同步；轮动接口只读并有版本。
- 摆动锚点有确认时间，特征无未来数据。
- 上先/下先/未触达和为1；同bar顺序未知不假装已知。
- 终值/期间极值/条件顶底区间不混用；共同路径概率及区间自洽。
- 固定价位触达概率跨期限单调；联合区间与边际区间分开。
- VIX/IV/OI/Gamma缺失和估计状态真实；没有无成本完美期权历史假设。
- 机会/风险/人气分开；凯利在交易分布之后，无账户金额臆测。
- 未校准、样本不足、陈旧和数据异常不能生成假概率进入正式榜。

## 回测
- 训练/校准/测试按时间，无随机跨日泄漏；跨边界标签被purge。
- 动态池历史和幸存者偏差有明确处理/限制。
- 收盘信号不能按已过收盘价成交；跳空/成本/同bar两边命中处理。
- 基准、去轮动、去期权、去Fib等比较有真实结果。
- 概率校准、价带宽度/覆盖、排序效果和净交易表现分别评价。
- 方向性阶段底、方向性阶段顶、无有效拐点是同一目标空间的互斥三分类，每行每周期严格合计100%；原可重叠顶底事件仅在双向洗盘诊断区出现，不用于主表方向排序。
- 主表和详情分别标出结构价带、ATR波动率回退带与期权约束后候选带；结构/期权缺失时不只显示`—`，也不把ATR回退冒充技术确认或期权边界。
- 期权特征进入概率前通过连续点时历史准入门槛并另训/另校准；样本不足时明确BLOCKED，Gamma/GEX/Flow缺失不补造。
- 模型置信度依据真实独立样本，不用模拟路径数充当样本数。
- 逐标的逐周期信度分级可审计；高确信必须有足够唯一交易日、无体制漂移且近期准确率至少高于多数类基线3个百分点；信度不改写概率或排序。
- 方向三分类校准曲线按所选5/10/21日周期显示预测均值、实际频率、样本数和日期分块区间；无成熟样本不画假曲线。
- 旧预测不可变；多个更新版本不事后择优。
- 挑战者晋级/回滚规则已登记；合成测试不当作盈利证明。

## 前端
- 100股数量、可比较预测数量、数据时间醒目。
- 机会↓、机会↑、风险↓、风险↑均是可点击按钮且状态正确。
- 数值排序、空值永远置底、同分稳定；切换周期同步数据与排序。
- 周期按钮完整标明5交易日（1周）/10交易日（2周）/21交易日（约1月），股票/指数表头与校准图均同步显示当前周期。
- 首页最上方越界预警固定展示5/10/21日三行及“跌破冻结下限/超过冻结上限”两列，覆盖常态股票和指数/ETF；基准run/date可见，21日注明约20日/月度窗口。
- 越界使用最近一个更早交易日冻结边界，禁止同日区间比较；严格小于/大于才计入，生产校验拒绝基准日不早于当前日、方向与价格关系不一致或非有限价格。
- 指数区标题仅为“指数方向性拐点”；13项覆盖含SOXL、SOXS、TQQQ、SQQQ，且不占100股名额。
- 四只杠杆/反向ETF按自身复权OHLC独立计算，不把指数概率乘以3、不把做多与反向结果互相镜像；详情披露每日重置、复利、波动损耗、费用与跳空风险。
- 指数结构价位矩阵覆盖13项×3期限，页面随全局周期显示13行；每行有NYSE常规交易日预计截止日、锚点、核心条件底/顶、尾部压力底/顶、相对锚点涨跌、位置、触发、失效、宽区间和事件状态。
- 结构矩阵明确标注价位与压力区不是概率；核心区优先条件路径、缺失时才标ATR回退，压力扩展不称为盘中极限，`not_ingested`事件不按中性处理且不改概率。
- 过滤不重算全池分位；临时股映射不改变常态池排名。
- 个股有多周期价带与完整研究/条件路径/风险，不只有分数。
- 手机可操作、键盘可访问、没有XSS、没有泄露密钥。
