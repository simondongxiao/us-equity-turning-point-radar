# 存储与内存：独立分组、细分轮动、顶底概率

## 1. 边界与数据对象
主研究组是一个便于比较的研究分类，不是官方GICS行业。用`research_group_id=storage-memory`，显示“存储与内存”。初始MU、SNDK、WDC、STX四只从原组迁移，不新加股票。主研究组单值，业务/行业研究标签多值；正式行业分类有来源才填，不能把研究标签伪装为官方分类。

| 代码 | 初始业务标签 | 解读限制 |
|---|---|---|
| MU | DRAM、HBM、NAND、SSD | 跨两个细分视图；不能把所有波动仅归于DRAM |
| SNDK | NAND、SSD | 不等于DRAM/HBM敞口，不跟随MU自动确认底部 |
| WDC | HDD | 按分拆后信息分类，历史业务与当前标签不同 |
| STX | HDD、HAMR | 技术标签不等于模型独立看多信号 |

业务标签的初始来源见`assets/research_taxonomy.json`及`sources.md`；访问核对日期2026-09-15。此配置是当前研究分类，只能从迁移生效时点向前使用，不能回填成过去已知信息。证券身份/交易资格/人气仍需真实首跑验证。

初始展示筛选：DRAM / HBM（MU）；NAND / SSD（MU、SNDK）；HDD（WDC、STX）。前两个视图有重叠，总数不得相加为五只。历史与周更新增成员按时点标签动态生成，不硬编码永远只有四只。

## 2. 三层轮动比较
A. 市场与大类：存储篮子对市场基准及其他科技研究组的相对表现。
B. 科技内部：存储对非存储半导体、软件、算力网络与光通信；研究更长的领先延续与短期切换，不预设“硬件涨完必涨软件”。比较窗口默认1/3/5/10/20交易日，预测期限仍为5/10/21交易日，不能混淆。
C. 存储内部：DRAM/HBM、NAND/SSD、HDD之间的相对表现；个股对剔除自身的宽存储篮子、最接近业务同行的差异。

比较样本应来自按时点有效的独立研究母池，不局限当前前100只。辅助基准不占100名额。第一版仅有四只时如实显示覆盖规模。不得为了凑同行把没有可比业务的热门股票塞进存储组。

MU同时属于DRAM与NAND暴露，所以包含MU的两个子篮子不是独立证据。保存overlap_issuer_ids；必要时用更广、按当时信息分类的同类样本，否则只给代理价差。非存储半导体等对照篮子原则上与存储剔除重叠发行人。含目标股的ETF不能称为已经剔除自身的纯行业因子。

只读复用旧复盘的`rotation_snapshot`；缺失细分在本新项目生成派生状态，保存parent_snapshot_id、taxonomy_version、membership_version、feature_version、as_of、available_at和method。不能改旧Skill，也不能用派生信号反复更新先验再当独立证据叠加。

## 3. 剔除自身与点时规则
对目标发行人i，先排除其所有股份类别/别名，再计算：

r_peer,-i,t = sum(j != issuer_i) w_(j,t-1) * r_(j,t) / sum(j != issuer_i) w_(j,t-1)

权重、成员资格及业务标签必须在收益窗口开始前已知且有效。默认滞后等权；要用市值/波动权重时记录滞后口径，不能按当天上涨后的市值重设权重。同期收益可在收盘后用于预测下一阶段，但未来日hazard不能读入未来真实同行收益。

计算个股对市场与行业因子的残差时，估计beta与残差标准化仅用当时可得历史；整个滚动历史每一天均按当时成员/标签剔除自身，不只在最后一天移除目标股。行业广度、领先者比例、波动等给个股使用的统计也应排除自身。公开组总览可以含所有组员，但标注“含自身组总览，非个股独立证据”。

证券ID以发行人和证券主表为准，不能仅靠字符串ticker。特别检查SNDK的不同上市实体/时期，以及WDC与SNDK分拆导致的业务边界与价格复权。不得把历史旧SNDK、合并期间WDC及当前SNDK硬拼成长时间序列；分拆前后WDC总收益调整须核验，业务暴露不能按当前标签向过去回填。未知ID禁止宣称剔除自身成功。

工具`scripts/peer_reference.py`提供单期元数据/时点/权重校验和发行人LOO参考计算，用于接入和合成测试，不是训练好的轮动或顶底模型；生产中仍需接行情、身份映射、完整历史因子和模型训练。

## 4. 小样本不能伪装为“板块共振”
初始工程阈值：剔除自身后至少3个可用发行人、有效权重样本量>=2.5、权重覆盖>=80%，滚动关系还需默认至少60个有效重叠交易日。这些是可调、需训练期检验的起点，不是最佳参数。

只有一个可比同行时，可以展示“单一同行代理”和真实收益，但不能给多股广度/机构一致行为/可靠行业先验。两个同样标`proxy_only`。没有同行时标`no_peers`；缺失收益、时间或身份不合格分别记录，不填0。

宽存储LOO、细分同行与更上层基准分别保留身份与含义。业务同行不足时可收缩到宽存储或更上层经验证的先验，但必须说明这是回退而不是纯DRAM/NAND/HDD信号。回退不能再被作为额外一票，不能重复使用相同信息。

## 5. 纳入原概率模型，不新增拍脑袋加分
候选特征：对市场/非存储半导体/软件的相对收益、RS斜率与加速度、领先持续时间、组内参与度、离散度、个股LOO残差、事件与行业状态交互。

同样的技术支撑，在“存储改善且个股LOO残差改善”与“市场反弹但个股残差恶化”中允许不同概率；参数由样本外检验得到。不能写成见到存储转强就+10%底部概率，不为四只股票编四套固定顶底逻辑。纳入竞争风险和共同scenario-set，继续输出修复、阶段顶底、首次触达及交易净收益，凯利仍在其后。

解释必须允许：MU单独走强；HDD强但NAND弱；指数修复而前期存储赢家转弱；存储总体修复但某股基本面事件破坏。没有数据就显示未分析，不把这些情景写成当天已发生。

## 6. 研究深度保留
对MU检视DRAM/HBM与NAND结构；SNDK检视NAND/SSD结构；WDC/STX检视HDD与数据中心暴露。可用指标包括出货量/bit或exabyte、ASP、库存、供给/产能与资本开支、毛利率、客户需求和技术产品事件。只在原文有数据时引用；缺数据列明，不把行业价格涨跌无条件传给所有细分。

事件用published_at/first_seen_at/available_at与原文证据，旧文章更新不当新催化。新闻/基本面只是原完整特征层的扩展，不因增加存储模块删除技术结构、价带、失效规则、VIX/期权、非科技研究或原文摘要。

## 7. HTML与排序
控制区新增一键“存储与内存·N”，旁边保留研究组下拉；选择后才启用细分下拉“全部细分 / DRAM-HBM / NAND-SSD / HDD”。类别切换清空冲突组/细分，不留下看似股票消失的无解筛选。提示当前显示n/当前视图总数，100股覆盖数字不变。

筛选只改变可见集合；机会/风险值、全池分位分、默认周期、四箭头排序和空值置底原样保留。不得为了突出存储而强制置顶买入榜。临时股可进入存储视图但不增加常态池名额；异步结果更新组筛选选项，新快照仍不混入旧榜。

存储视图在控制区下方显示简短板块摘要；详细矩阵折叠。没有真实快照时明确显示未接入，不用种子标签生成涨跌结论。个股详情新增业务标签/LOO状态/同行名单/样本量/缺口，保留原全部研究块。

## 8. 每周复核
每周除了原人气调池，还核对存储母池新增热门股、当前四只资格和标签、细分覆盖缺口。不设永久名单或强制买入权重；存储热门股退出时必须记录资格/热度/配额原因，不能因字段改名意外删除。没有合格候选时报告覆盖不足，不能强填低流动性股。历史成员与旧预测完全保留。

## 9. 增量回测与验收
同一标的/同一日期窗口比较：原B3；B3+宽存储LOO；再加细分同行/交互；新增模块消融。新增特征版本先挑战者/影子运行，不自动沿用原模型校准器。界面/分类迁移可独立上线，但概率引擎升级另验收。

分层报告MU/SNDK/WDC/STX及存储整体、DRAM/HBM/NAND/SSD/HDD标签切片、市场修复个股未修复、指数反弹前期赢家走弱、财报/分拆/短历史/缺失数据。交叉标签切片只作诊断，合并业绩时按唯一预测ID去重。

同时检验概率、区间覆盖/宽度、排序和净收益；按日期/事件分块评价，不把四股同日走势当四次独立宏观验证。样本不足保持低可信，不以“存储组分出来了”宣称预测更准。
